# Historical Atlas

A small, static educational website inspired by the supplied homepage brief and reference. It uses local HTML, CSS, JavaScript, SVG artwork, and the supplied landmark photos.

## Open the site

Open `index.html` in a browser. No build step or third-party library is required.

## Pages

- `index.html` — introduction, how-it-works section, and featured historic sites
- `explore.html` — six-continent map with clickable pins and country/site stories
- `about.html`, `contact.html`, `services.html` — themed placeholder pages

Shared styling lives in `css/style.css`. Region and landmark content lives in `js/heritage-data.js`; `js/explore.js` renders it when a map pin is selected. Artwork and photos live in `Assets/`.
