# Pin and Explore

A static educational website about famous historical sites. Pages are built with HTML and CSS; map navigation uses links and anchors.

## Open the site

Open `index.html` in a browser.

## Pages

- `index.html` — home
- `explore.html` — world map with links to continents
- `asia.html`, `europe.html`, `africa.html`, `north-america.html`, `south-america.html`, `oceania.html` — continent maps, country pins, and landmark stories
- `about.html` — project information
- `contact.html` — team and contact details

Map and landmark artwork is in `Assets/`; shared styling is in `css/style.css`.
