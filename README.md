# Pin and Explore

html/css web for group 3

## Open the site

Open `index.html` this is the home page and default

## Pages

- `index.html` — home
- `explore.html` — world map with links to continents
- `asia.html`, `europe.html`, `africa.html`, `north-america.html`, `south-america.html`, `oceania.html` — continent maps, country pins, and landmarks
- `about.html` — project information
- `contact.html` — team and contact details

image and design assets is in `Assets/` and shared styling is in `css/style.css`.
